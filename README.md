# ContactManagementSystem

A console-based **Contact Management System developed using Core Java** to demonstrate and practically implement major Object-Oriented Programming (OOP) concepts.

##Project Overview

This project allows users to add, search, display, and delete contacts through a simple menu-driven console application. It supports different types of contacts, including **Personal Contacts** and **Business Contacts**.

The main objective of this project is to demonstrate how Java OOP concepts can be applied together in a real-world application.

## Features

* Add general contacts
* Add personal contacts
* Add business contacts
* Display all contacts
* Search contacts by name
* Delete contacts
* Track total number of contacts
* Validate phone numbers
* Detect duplicate contacts
* Copy existing contact objects
* Demonstrate inner classes

## OOP Concepts Implemented

* **Encapsulation** – Private fields with getters and setters
* **Inheritance** – PersonalContact and BusinessContact extend Contact
* **Abstraction** – Abstract Person class
* **Interfaces** – ContactOperations interface
* **Polymorphism** – Different contact types handled through Contact references
* **Exception Handling** – try-catch blocks for error handling
* **Custom Exceptions** – InvalidContactException and DuplicateContactException
* **Static Block** – System initialization
* **Static Methods** – Contact count and phone validation
* **final Keyword** – Constants
* **Method Overloading** – Multiple insert() methods
* **Inner Class** – ContactDetails inside Contact
* **Composition** – Contact contains an Address object
* **Copy Constructor** – Creating duplicate Contact objects
* **Default Interface Method** – Activity logging using a default interface method

## Technologies Used

* Java
* Core Java
* Object-Oriented Programming
* Collections (`ArrayList`)
* Exception Handling
